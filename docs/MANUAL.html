02 · quickstart

Diagnostique antes de instalar.

python -m hpp doctor
python -m hpp graph --view operational --format mermaid
python -m hpp install --bundle reliable-coding --host codex --target ../repo
python -m hpp benchmark -k 3

O comando de bundle é somente plano. A cópia real usa o kit_doctor.py install --kit ... --apply do módulo.

04 · loops e waves

Paralelismo segue o WorkGraph.

A spec vira unidades com dependências e acceptance criteria. O compilador rejeita ciclos, cria waves topológicas e fecha cada barreira antes de liberar dependentes.

python -m hpp work plan examples/reliable-coding/workgraph.json
python -m hpp work waves examples/reliable-coding/workgraph.json
python -m hpp resume

Autoprompt deriva continuidade; o done gate decide conclusão.

05 · política

Advisory não se fantasia de bloqueio.

0 · OK

Allow

Nenhuma regra de risco casou.

1 · WARN

Audit

Registra o risco; não impede.

2 · BLOCK

Enforce

Detector confiável impede a ação.

python -m hpp policy check --mode audit --command "git push origin main"
python -m hpp policy check --mode enforce --command "git push origin main"

06 · prova

Capacidade e confiabilidade não são a mesma métrica.

pass@k mede se um caso passou ao menos uma vez. pass^k mede se passou sempre. Uma release crítica exige piso repetível no universo declarado.

python -m hpp eval run examples/reliable-coding/benchmark-suite.json -k 3 --gate both
python -m hpp benchmark -k 3 --json
